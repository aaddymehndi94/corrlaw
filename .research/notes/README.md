# Detailed notes

Use compact files such as `20260921T153000Z-T05-qbc-failure.md`.
Record: task, hypothesis/question, change, command/run ID, observed result, error
or evidence paths, decision and next action. Prefer conclusions and reproducible
facts over full tool logs or private reasoning transcripts. Link from STATE/PLAN.
Workers write separate named notes; only the lead merges decisions into shared state.
