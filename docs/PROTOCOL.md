# CorrLaw experimental protocol
Status: READY_TO_FREEZE
Protocol ID: v1
Finalized: 2026-09-21, after A/B development and before any C/D/E/F run.

## Question and scope
Does explicit near-nullspace candidate augmentation add useful acquisition value
beyond ordinary QBC, diversified QBC, uniform random and regularized D-optimal?
The primary benchmark is finite-library regression on six simulated ideal systems.
Development: A/B; confirmation: C/D/E/F. A separate optional PySR static development
check is not a confirmation acquisition comparison. No novelty/discovery is presumed.

## Binding implementation and physical assumptions
[Benchmark contract](BENCHMARKS.md) specifies dimensional equations/reference scales,
all domains, perturbation and rejection distributions, noise, independent controls,
shuffled controls and restricted-query controls. [Method](METHOD.md) specifies
all fitting, filtering, witness, acquisition, tie and metric decisions. These files
are freeze inputs along with the code, tests, configurations and dependencies.
The primary setting supplies incomplete physical priors equally: bounds, generic
dimensionless grammar, complexity/coefficient caps, output scale and noise level.
A boundary-aware circle identity is tested; no prior-aware numerical sweep is claimed.

## Fixed method choices retained after development
Dictionary generated by |a|+|b|≤3; polynomial on signed domains, exponents ≥-1 on
strictly positive domains. No task-specific feature insertion. A–E representable;
F's reciprocal of a sum is absent by design. Columns RMS-scaled using public probes.
One full fit plus eight bootstrap paths; supports 1,2,3,4,6,7. Common selected point
model for every policy. Seven-term maximum, coefficient magnitude cap 20 in scaled
coordinates. Admissibility RMSE ≤0.002+3σ on both fitting and calibration labels;
maximum acquired-point residual ≤0.002+4σ. No post-development threshold adjustment.
Witnesses search two/three-column smallest-eigenvalue directions, direct residual
ratio ≤0.1, public-probe RMS normalization, alpha {-1,-0.25,0.25,1}, up to 12 accepted
directions. Both expressions must satisfy the common admissibility checks.
Diversified committee retains max(7,floor(0.7p)) feature columns per bootstrap.
QBC and augmented QBC use identical population prediction variance in declared
output units. D-optimal uses ridge 1e-4 and Cholesky leverage on the same features.
Ties use rtol=1e-10/atol=1e-14 with reproducible random selection among tied IDs.
No feasible off-surface measurements are available in restricted-query controls.

## Endpoints and statistical units
Primary: off-preparation NRMSE in the physical output reference units (scale 1),
and trapezoidal AUC over [0,1,2,4,8] divided by 8. Also report same-preparation error,
false consensus (off error >0.1 and RMS committee spread <0.05), witness coverage/
admissibility, operational failures, labels, runtime and cumulative process peak RSS.
No hidden-test-dependent normalization or thresholds. Quantities may be computed
on hidden inputs only in the evaluator, never in acquisition.
Secondary: symbolic equality of six-decimal rounded coefficients with raw magnitude
below 1e-6 removed; clearly labeled as rounded recovery, not proof of exact fitted
floating-point equality. A separate dense-grid recovery endpoint is not included;
independent hidden box samples provide numerical generalization evidence only.

For each task and policy, average constrained conditions within each seed, then
report seed-level means and ranges. Paired AUC differences are augmented minus each
comparator using exactly matched conditions; negative favors augmentation. Report
all five seed values/ranges, without treating hidden points or multiple conditions
as independent replicates. No p-value or population-wide significance claim is
planned for this small hand-selected suite. Conditions remain separately available
in CSVs and immutable unit files. F's misspecification results are explicit and may
not be dropped from an unfavorable aggregate.

## Execution, failure and reproduction rules
One heavy process, at most four requested numerical threads, CPU only. Development
360-unit execution took 86.23 s; allow 1,800 s for confirmation, within the original
sprint deadline. Record wall time, fitting/augmentation time and cumulative process
RSS. Witness instrumentation runs for all policies; subtract its measured cost
when discussing non-augmented operational acquisition cost. Timing is descriptive.
Store completed units atomically with full candidates/witnesses/query records.
Failures retain their exceptions without default numeric scores. A timeout is an
incomplete run, never a negative scientific result. Artifact validation must compare
expected/completed sets, pairing, labels, witness bounds and re-evaluated errors.
No failed policy/seed can be silently excluded. Resume requires matching engine,
config and artifact hashes; preserve orphaned files and use a new run ID if unverified.

Before confirmation inspect only A/B outcomes. After confirmation do not alter
methods, metrics or configurations and call the same seeds fresh confirmation.
Any correctness bug requires retaining/invalidating affected evidence and a new
protocol with fresh seeds. Preselect reproduction unit
C-s91001-w0-n0.01-constrained-augmented_qbc from confirmation-v1-001. A new process
must exactly match scientific JSON (excluding timing/RSS); save mismatch if any.
Figures and tables must regenerate from saved artifacts.
